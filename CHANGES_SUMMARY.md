# ZeroGravity Group — Website Update Summary

**Date:** 2026-06-20

- **Updated logo** — the official ZeroGravity logo now appears in the header, replacing the temporary placeholder.
- **Updated tab icon** — the browser tab icon (favicon) now uses the official logo too.
- **Clearer header** — the header now has a subtle frosted-glass look, keeping the logo, email, and toggle easy to read over any background.
- **Centered section content** — content on every section (Home, About, Companies, Achievements, Contact) is now vertically centered instead of sitting at the top with a large empty gap below.
- **Dark mode unchanged** — the original dark design is fully preserved; everything above is in addition to it.
